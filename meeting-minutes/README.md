# Meeting minutes

Minutes are written **after** a session, from what was said in it, by whoever
holds the Documentation Lead role that week. Nothing in this folder is
back-filled: a meeting that has no minutes here is a meeting whose minutes were
never written, and that is a more useful thing for a reader to know than a
plausible reconstruction would be.

What this folder holds today:

| File | What it is |
| --- | --- |
| [`TEMPLATE.md`](TEMPLATE.md) | The shape every set of minutes takes. |
| [`task-10-mentor-review-agenda.md`](task-10-mentor-review-agenda.md) | The agenda for the Task 10 mentor review, written before it. |

An agenda is a plan and is written in advance; minutes are a record and are
written afterwards. They are kept as separate files so the two are never
confused.

**Where the week-by-week record actually lives.** The per-member weekly notes
the brief asks for are in [`../weekly-reports/`](../weekly-reports/). Those six
were compiled in Task 10 from this repository's commit record, and each one says
so in its header.
